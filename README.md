# 🚀 Karmiq – Empowering Workforce, Simplifying Hiring

Karmiq is a **Django-based multilingual workforce hiring platform** that bridges the gap between **daily wage workers** and **contractors** through a transparent, fast, and intermediary-free hiring process. It simplifies workforce management by enabling direct job posting, applications, and communication while making opportunities accessible in multiple regional languages.

---

## 🌟 Key Features

- 👷 Worker & Contractor Registration
- 🌍 Multilingual Support (English, Telugu, Hindi & Tamil)
- 📍 Location-Based Job Discovery
- 💼 Job Posting & Management
- 📝 One-Click Job Application
- 📋 Applicant Tracking System
- 💬 Real-Time Chat Between Workers & Contractors
- 🔐 Secure User Authentication
- 📊 Role-Based Dashboards
- 📱 Mobile-First Responsive Design

---

## 🎯 Problem Statement

Hiring daily wage workers often depends on intermediaries, leading to delayed communication, unfair wages, and a lack of transparency. Both workers and contractors face challenges in finding reliable opportunities and skilled manpower efficiently.

---

## 💡 Our Solution

Karmiq provides a digital platform where contractors can post jobs and manage applicants, while workers can discover nearby opportunities, apply instantly, and communicate directly—eliminating the need for middlemen and creating a fair, transparent hiring ecosystem.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/vyshnavichandra7/karmiq-website.git
```

### Navigate to the Project

```bash
cd vrtp
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Development Server

```bash
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
